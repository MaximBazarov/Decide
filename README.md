# Decide

Decide is a Swift package that provides a shared environment for managing state across different parts of your application.


# Installation

Adding the dependency 

## Swift Package Manager

To install `Decide` by adding the proper description to your [Swift Package Manager](https://swift.org/package-manager/) `Package.swift` file:
```swift
dependecies: [
    .package(url: "https://github.com/MaximBazarov/Decide.git", from: "2.0.0")
]
```
